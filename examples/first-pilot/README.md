# 첫 실전 파일럿

이 폴더는 방법론을 실제 제품에 처음 적용했을 때 **방법론 자체가 유용했는지** 검증하는 기록 양식입니다. 제품 코드나 비밀값을 넣지 않습니다.

## 파일럿의 최소 범위

- 실제 사용자 또는 운영자가 확인할 수 있는 기능 1개
- Story는 1~3개
- 공유 계약이 없다면 Main 단독 실행
- 새 함수·행동은 TDD로 `RED → GREEN → REFACTOR`
- 로컬 테스트 결과와 수동 검수 결과를 모두 남김

## 성공 기준

- 목적·성공 기준·비목표가 구현 전 명시됐는가
- 중요한 기술·권한·구조 결정이 기록됐는가
- Story별 영향·허용 행동·거부 행동·검증 방법이 있었는가
- 테스트가 구현 전 실패했고, 구현 후 통과했는가
- 오류가 생기면 기록 → 재검수 → 학습 인제스트까지 이어졌는가
- STATUS, index, MOC가 서로의 역할을 침범하지 않았는가
- 절차가 실제 작업을 지연시킨 부분과 지켜 준 부분을 구분할 수 있는가

## 회고 양식

```markdown
## <프로젝트> — <기능> / YYYY-MM-DD

- 목적:
- 성공 기준:
- 비목표:
- Story 수:
- 학습 모드로 처리한 결정:
- 실행 모드로 적용한 기본값:
- TDD 증거: RED 명령·결과 / GREEN 명령·결과
- 수동 검수 증거:
- 발견한 오류와 인제스트 결과:
- 방법론이 방지한 문제:
- 불필요하거나 느렸던 절차:
- 다음 템플릿 수정 제안:
```

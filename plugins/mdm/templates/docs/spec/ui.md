## 화면 목록

목업·검수 칸은 예/아니오로 적는다.

| # | 화면 | 종류 | 목업 | 검수 |
|---|---|---|---|---|
| | | 목록/상세/편집/빈상태/로딩/오류/권한없음 | | |

- [ ] 데이터가 하나도 없을 때

- [ ] 오류가 났을 때
- [ ] 권한이 없을 때
- [ ] 결과가 아주 많을 때

## 규칙 준수 점검

- [ ] 화면당 핵심 행동이 하나로 정해져 있다
- [ ] 빨간색이 지연·오류·위험에만 쓰인다
- [ ] 누를 수 있는 것과 없는 것이 시각적으로 구별된다
- [ ] 되돌릴 수 없는 행동에 확인 절차가 있다
- [ ] 상태 표시 어휘가 `docs/spec/domain.md`와 일치한다
- [ ] 목록의 기본 정렬이 정해져 있고 보인다

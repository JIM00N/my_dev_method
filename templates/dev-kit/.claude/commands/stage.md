단계: $1

1. `docs/status/STATUS.md`를 읽고 현재 단계·프로파일·열린 것을 확인한다. 인자가 없으면 STATUS의 현재 단계를 쓴다.
2. `docs/guides/profiles.md`에서 이 프로젝트 프로파일이 이 단계에 요구하는 범위를 확인한다. 프로파일이 스킵하는 절은 수행하지 않는다.
3. 해당 `docs/guides/S<n>-*.md` **하나만** 읽는다. 그 가이드가 "입력"으로 지정한 문서만 추가로 읽는다. `docs/` 전체를 읽지 않는다.
4. 모드를 맞춘다.
   - **S1~S4 (설계)** → 인터뷰 모드. thinking을 높게 쓴다. 답이 실제 선택을 바꾸는 질문만, 한 번에 한 결정 묶음씩. 새 기술·권한·구조 선택이면 `docs/guides/decision-modes.md`를 먼저 읽는다.
   - **S5~S6 (구현)** → 검수 루프 모드. 인터뷰는 끝났다. 구현 → 검수 요청 → 사람 확인 → 피드백 → 수정.
5. 단계가 끝나면 산출물 `docs/spec/*.md`를 쓰고, **가이드 말미의 DoD를 실제로 하나씩 대조한다.** 대조하지 않은 완료 보고는 하지 않는다.
6. `docs/status/STATUS.md`의 단계 진행판과 최종 갱신을 고친다.

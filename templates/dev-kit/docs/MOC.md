# docs MOC — 개발 문서 탐색 지도

이 파일은 문서 **관계와 탐색 경로**를 보여준다. 파일의 전체 목록·간단한 카탈로그는 `index.md`가 맡는다.

```text
현재 작업
→ status/STATUS.md
→ 현재 단계 guide
→ 해당 spec
→ 필요할 때 plan / quality / decisions
```

- 설계 방법: `guides/` MOC → 현재 S1~S4 가이드
- 설계 사실: `spec/` index → product/domain/interface/stack/architecture/ui
- 실행 계획: `plan/` MOC → roadmap → 활성 cycles
- 현재 상태: `status/MOC.md` → STATUS → 필요한 archive
- 품질·에러 학습: `quality/` index → issues → error-learning-ingest guide → rules-learned
- 큰 결정: `decisions/` index → ADR

원칙: MOC는 “어디서 무엇을 찾아야 하는가”, index는 “어떤 파일이 존재하는가”를 담당한다.

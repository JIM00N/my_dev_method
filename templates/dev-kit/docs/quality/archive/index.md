# quality archive — 해결된 이슈 카탈로그

열린 이슈는 `docs/quality/issues.md`에만 둔다. 재검수까지 통과한 이슈는 유형별 하위 폴더에 보관한다. 탐색 경로는 별도 `MOC.md`를 본다.

권장 유형: `authorization/`, `data/`, `integration/`, `configuration/`, `ui-ux/`, `reliability/`, `performance/`, `test/`.

각 보관 이슈에는 재현 절차, 전제 조건, 원인, 조치, 재검수 근거, 재발 방지 규칙 링크를 남긴다. 같은 유형이 두 번째면 `docs/quality/rules-learned.md`에도 승격한다.

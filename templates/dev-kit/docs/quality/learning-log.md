# 에러 학습 인제스트 로그

Error Learning Agent가 새 에러 기록을 종합한 결과만 남긴다. 원본 이슈의 재현·수정 내역은 `issues.md`와 `archive/`가 소유한다.

## 기록 양식

```markdown
## YYYY-MM-DD — <유형> 종합
- 원본 이슈: #000
- 공통 원인:
- 영향 Story/Epic:
- 일반화 가능한 규칙 / 규칙 아님:
- 추가·수정한 검수 시나리오:
- 자동 테스트로 승격한 것 / 승격 불가(이유):
- 영향을 받는 문서와 Main 통합 상태:
- 남은 질문:
```

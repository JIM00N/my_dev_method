# status archive MOC — 과거 상태 탐색

이 MOC는 현재 상태가 아니라 **왜 과거에 막혔고 어떻게 해소했는지**를 찾을 때 사용한다. 파일 목록은 `index.md`에 둔다.

- `blockers/`: 해결된 외부 의존성·승인 대기·접근권한 차단과 해소 경위
- `snapshots/`: 단계·사이클 전환 직전의 STATUS 스냅샷

다른 유형의 과거 기록은 이곳이 아니라 각 소유 영역으로 간다: Story·Epic은 `plan/archive/`, 이슈는 `quality/archive/`, 큰 결정은 `decisions/`.

# status — 현재 상태 카탈로그

`STATUS.md`는 **현재만** 담는 세션 연속성 스냅샷이다. 현재가 아닌 완료·해결·과거 상태를 계속 누적하지 않는다. 상태 사이의 관계와 아카이브 경로는 `MOC.md`를 본다.

## 항상 읽을 파일

- `STATUS.md` — 현재 단계, 병렬 작업, 열린 차단요인, 다음 행동. **200줄 이하 하드 제한.**

## 파일 목록

| 파일 | 역할 |
|---|---|---|
| `STATUS.md` | 활성 작업·차단요인·다음 행동만 담는 현재 스냅샷 |
| `MOC.md` | 현재와 archive 사이의 탐색 경로 |
| `archive/index.md` | 상태 archive 파일 카탈로그 |
| `archive/MOC.md` | 과거 상태 탐색 허브 |

`STATUS.md`의 200줄 제한·병렬 상태 원칙은 `MOC.md`에서 안내한다.

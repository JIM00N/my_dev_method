# upstream — 계획 문서 스냅샷 (읽기 전용)

이 폴더는 **요구사항이 태어난 곳의 사본**이다. 그곳이 어디든 상관없다 — 기획 도구(SaaS·MCP)일 수도,
저장소에 이미 있던 PRD 파일일 수도, `/mdm-plan` 이 직접 만든 계획일 수도 있다.
**어디서 왔든 자리는 같고 취급도 같다.** 이 문서에서 그곳을 **상류**라 부른다.

## 규칙 ★

- **손으로 고치지 않는다.** 이 문서들의 정본은 상류에 있다.
  고치면 다음 `/mdm-adopt --sync` 에서 조용히 덮이므로, `.claude/scripts/check-consistency.sh` 가 해시로 잡아 **실패시킨다.**
- 요구사항을 바꾸려면 **상류에서 고치고 `/mdm-adopt --sync` 로 받는다.**
  (`/mdm-plan` 이 만든 계획이면 상류가 곧 이 저장소다 — 그때도 스냅샷을 직접 고치지 말고 `/mdm-plan` 을 다시 돌린다)
- 상류가 담지 않는 것은 `docs/spec/` 이 정본이다. **무엇을 담고 무엇을 안 담는지는 미리 정해져 있지 않다** —
  `/mdm-adopt` 가 확인해 판정하고, 경계는 `docs/spec/source-map.md` 1절 표가 정한다.

## 파일

**문서 개수와 종류를 고정하지 않는다.** 상류가 준 것을 그대로 받는다 — 한 장짜리 하나일 수도, 넷일 수도 있다.
아래는 키트가 자리만 깔아 둔 **빈 양식**이지 요구 목록이 아니다.

| 파일 | 무엇 | 없으면 |
|---|---|---|
| `docs/upstream/prd.md` | 문제·목표·비목표·성공 기준 | 요구사항 ID의 출처가 없다 |
| `docs/upstream/features.md` | 기능 명세 — 요구사항 ID의 주 출처 | 위와 같음 |
| `docs/upstream/userflow.md` | 사용자 흐름·화면 이동 | 화면 ID를 뽑을 수 없다 |
| `docs/upstream/wireframe.md` | 화면 목록 텍스트 인덱스 (이미지는 링크로) | 화면 정합 검사가 비어 돈다 |
| `docs/upstream/plan.md` | **`/mdm-plan`이 직접 만든 계획** (외부 계획이 없을 때) | 계획 없이 시작하는 경로가 막힌다 |
| `docs/upstream/manifest.tsv` | **기계용 수집 기록** — 파일·출처·수집시각·해시 | 무결성 검사가 돌지 않는다 |

- **해당 없는 양식은 지운다.** 외부에서 계획을 받아 왔으면 `plan.md`를, `/mdm-plan`으로 만들었으면 나머지를 지운다.
  지운 파일은 `manifest.tsv`에서도 뺀다. **빈 양식을 남겨 두면 "수집했는데 비었다"와 구분되지 않는다.**
- 상류가 한 문서에 전부 담았으면 파일도 하나다. 억지로 넷으로 쪼개지 않는다.
- 상류가 이 이름들과 다른 구성을 준다면 그쪽 이름을 쓴다. 이 표에 맞추려고 내용을 옮기지 않는다.

`manifest.tsv` 의 출처 칸은 세 갈래다:

| 출처 표기 | 뜻 |
|---|---|
| 도구 이름 | 외부 기획 도구에서 받았다 |
| 저장소 경로 | 이 저장소에 이미 있던 문서를 스냅샷으로 떴다 |
| `self:plan` | `/mdm-plan` 이 직접 만들었다 |

## 화면 자료가 이미지일 때

기계는 이미지를 검사하지 못한다. `/mdm-adopt` 가 **화면 ID 텍스트 인덱스**를 뽑아 남긴다 —
그 인덱스가 `docs/spec/source-map.md` 3절 화면 매핑표의 근거가 되고, 검사 대상이 된다.

```
| SC-001 | 주문 목록 | (이미지: 상류 링크) |
```

## 수집

```
/mdm-adopt          최초 도입 — 찾기 · 수집 · 교차 대조 · ID 정리 · 계약 확인
/mdm-adopt --sync   상류 재수집 — 바뀐 것만 재검토로 표시
/mdm-plan           계획이 아예 없을 때 — 키트가 직접 만든다
```

`/mdm-adopt` 는 **저장소 안을 먼저 뒤진다.** 없으면 밖에 있는지 묻고, 그래도 없으면 `/mdm-plan` 으로 보낸다.

**검사는 어떤 외부 도구도 부르지 않는다** — 이 폴더의 스냅샷만 본다.
그래서 MCP가 죽어도, 네트워크가 없어도, CI에서도 검사가 돈다.

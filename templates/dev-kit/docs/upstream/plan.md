# 계획 (키트가 만든 것)

**미작성** — `/mdm-plan`이 만들어 이 파일을 통째로 대체한다. 손으로 채우지 않는다.

계획 문서가 저장소에도 밖에도 없을 때 `/mdm-adopt`가 `/mdm-plan`으로 보내고, 그 결과가 여기 들어온다.
**키트가 만들었어도 자리는 같다** — `manifest.tsv`의 출처만 `self:plan`으로 적어 외부 수집과 구분한다.

담기는 것 (`docs/guides/plan.md` P3):
문제 한 문장 · 사용자와 난이도 사분면 · 낱말 정의 · **요구사항 + 검증 조건 목록** ·
화면 목록 · **이번에 만들지 않을 것** · 성공 지표와 **부작용 지표** · 아직 모르는 것 · 가정

외부에서 계획을 받아 온 프로젝트라면 이 파일은 지운다 (`manifest.tsv`에서도 뺀다).
